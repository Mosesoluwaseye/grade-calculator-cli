Grade Calculator CLI

A Rust-powered command-line application that helps students calculate grades automatically and assign letter grades based on average scores.

Features

  • Calculate average scores
  • Automatically assign letter grades
  • Simple and easy-to-use command-line interface
  • Built with Rust
